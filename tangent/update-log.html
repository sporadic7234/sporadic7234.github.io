Tangent Update Log

stylish slope game

10/15/2025:

  • Maintaining high style ranks will allow you to survive getting hit so more risks can be taken i.e. speed can be comfortably gained without immediately dying to a treblock
    • If this effect is active, the ball will change appearance
    • Initially, this activates at S rank and above. However, getting hit will increase the rank required to activate the effect up to P rank (S -> SS -> SSS -> P)
  • Treblock obstacles have been made 10% bigger to make them less frustrating
  • Reduced overall camera FOV to improve visibility over distance

10/14/2025:

  • Added a sound adjust menu that appears when you first start the game
  • Pressing [esc] or [tab] will pause your game and bring up the sound menu at the cost of some style
  • Style ranks S and above have had their style drain rates increased slightly

10/13/2025:

  • SS rank's score multiplier increased from x2.25 -> x2.5
  • SSS rank's score multiplier increased from x2.5 -> x3
  • New ability: Press [W], [S], [up], [down], [shift], [ctrl], [space], [mouse1/2/3] to "crouch" and decrease your vertical velocity and sideways acceleration. Can be spammed for quickly move yourself downwards or for more precise movement
  • Small tweaks to the HUD, including a new "speedrun" timer that will be expanded upon eventually
  • Major backend code changes to everything involving the player. This doesn't affect gameplay, but should make developing easier

10/12/2025:

  • Initial release
  • Also some day 1 patches because doing things right the first time is hard
